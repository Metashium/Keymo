How to Connect?

Follow these steps to connect Keymo.

1. Install Keymo

GET IT ON
Google Play
DOWNLOAD APK
GitHub

2. Install Keymo Server

GET IT FROM
Microsoft
DOWNLOAD EXE
GitHub

3. Connect

1
Connect your devices to the same Wi-Fi network.
2
Launch both Keymo and Keymo Server.
3
In Keymo, tap the gear icon, go to the CONNECTION tab and scan the network. Your device should appear. Tap it and accept the connection request on Keymo Server.

Troubleshooting

Your device doesn't appear after scanning

Try typing the IP address manually. You can use the IP adress in Keymo Server.

Connection keeps failing

Make sure Windows Firewall is not blocking Keymo Server. When prompted, click Allow. You can also check this in Windows Firewall settings and allow Keymo Server manually.

It disconnects frequently

Your phone may be switching to mobile data. Make sure Wi-Fi is stable and that your phone isn't set to save battery by turning off Wi-Fi in the background.

Keymo can't find the server at all

Make sure Keymo Server is open and online before scanning. It needs to be running for your phone to detect it.
